## 🚀 Featured Projects

### 🎓 Mentor Booking Platform
A web app where people find a mentor by skill and book time with them. Anyone can sign up as a mentee and switch on mentoring later.
- Email/password, Google and Facebook sign-in (ASP.NET Core Identity + OAuth)
- Booking lifecycle: Pending → Confirmed / Rejected / Cancelled → Completed, with double-booking checks
- Mentor availability slots, search by name, skill or title, SMTP email notifications

`C#` `ASP.NET Core MVC` `EF Core` `SQL Server` `Bootstrap`

### 🛒 Supermarket Billing System
A Windows Forms app that runs a small supermarket's day: stock, billing, customers, staff roles and reports.
- Stock updates automatically as items are sold
- Billing with discounts and printed receipts, all saved to SQL Server
- Customer profiles with order history, plus sales and inventory reports

`C#` `Windows Forms` `SQL Server` `ADO.NET`
